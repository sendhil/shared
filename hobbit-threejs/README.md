# Hobbit Three.js

Three interpretations of the story prompts, kept side by side for comparison.

- [Luna](./luna/) — the first realistic 3D village route.
- [Sol](./sol/) — the live stylized twilight tableau built from the second prompt.
- [Astra](./astra/) — The Unchanging Hill, a polished miniature film built by GPT-6 Astra.

Sol and Astra use the exact [shared comparison prompt](./shared-prompt.md), which is kept here for future model runs.

The public versions are available from the [shared showcase](../site/).
