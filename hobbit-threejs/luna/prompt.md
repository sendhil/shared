# Luna prompt lineage

Luna came from the first prompt pass: turn the supplied literary-page image into a complete browser-based Three.js audiovisual short while preserving the page’s named characters, place, history, rumors, emotional contrasts, and warning signs.

The prompt asked for:

- a realistic procedural village route rather than a generic fantasy demo;
- a 90–150 second cinematic sequence with one master timeline;
- original geometry, architecture, character designs, sound, narration, and camera language;
- visible propagation of the birthday news through the community;
- visual metaphors for wealth, travel, hidden treasure, unchanged aging, and suspicion;
- play, pause, restart, seeking, captions, mix controls, orbit view, and graceful audio/WebGL fallbacks;
- no copied prose, adaptation designs, recognizable performances, or downloaded production assets.

This file is a prompt capsule rather than a reproduction of the source page or the full conversation. Sol will carry the second prompt pass when that version is built.
